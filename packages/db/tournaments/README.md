# Регламенты турниров

Один файл `<slug>.json` на турнир: стадии, группы, сетка (узлы и переходы), итоговые места. Готовится руками (через Claude)
по анонсу организатора и Liquipedia, применяется командой:

```bash
pnpm --filter @df/worker cli format <slug>
```

Применять можно сколько угодно раз — команда идемпотентна. После разметки, если карты переехали между стадиями, пересчитать очки:
`pnpm --filter @df/worker cli score <slug>`.

## Когда что заполнять
1. **До старта** (как только организатор опубликовал формат и расписание):
   - `stages` — стадии фэнтези с окнами дат (`from`/`to`, в часовом поясе `utc_offset`). Окно стадии — это и граница,
     по которой сбор матчей раскладывает карты. Дедлайн стадии = начало её первой карты (02 §2): до игр его даёт `deadline`
     стадии или `at` её первой серии (время по расписанию, ISO с часовым поясом).
   - `groups` — составы групп;
   - `series` — все узлы сетки сразу, с ключами (`key`), переходами `win`/`lose` и форматом (`bo`). Команды — где известны
     (стартовые матчи групп), иначе `[null, null]`.
   Команда создаёт узлы со статусом `scheduled`; сбор матчей (`cli ingest`) приклеивает карты к узлу с той же парой команд в окне стадии.
2. **После каждой стадии** — вписать команды в узлы следующей стадии и применить снова. Если матч уже сыгран раньше, чем узел
   заполнили, сбор создаст серию сам, а повторное применение регламента поставит её в узел (пустой узел удаляется).
3. **После турнира** — `standings`: место (`place`, нижняя граница диапазона: 5 для 5–6) и стадия вылета (`out_after`).

Команда печатает «серии без узла в регламенте» — сыгранные серии, которым не нашлось места (опечатка в командах, лишний
тай-брейк, перенос матча за окно стадии). Их нужно дописать в файл.

## Правила файла
- Команды — по тегу из таблицы `teams` (`PARI`, `TS`, `YDX`…).
- Если одна пара команд играет в одной стадии дважды (GSL: стартовый и решающий матч), узлы в файле идут в порядке игр.
- Ключи узлов (`A-O1`, `UBQF1`, `GF`) хранятся в `series.bracket_key` и не меняются: на них будут ссылаться прогнозы.
