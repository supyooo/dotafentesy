# 05. Устройство прототипа

`prototype/index.html` — один файл (~220 КБ): CSS + разметка всех экранов + один `<script>` в IIFE (`(function(){ … })();`).
Без сборки и зависимостей. Шрифты — Google Fonts: Saira (с осью ширины), Saira Expanded, IBM Plex Mono + шрифты оформлений турниров.
Фото — `photos/*.webp`, оформления турниров — `brand/`, данные — `data/*.json` (грузятся fetch'ем; открывать только через сервер). См. docs/10.
Все функции внутри IIFE (он `async`: сначала грузит JSON): из консоли браузера они недоступны (кроме `window.DFIntro`). Чтобы дёрнуть код из теста, вставляй его перед `})();` в копии файла.

## Роутинг
Хеш `#p-<view>`, функция `route()`, словарь `VIEWS` (флаг `tour:1` — экран внутри турнира, показывает нижнюю панель).
| Хеш | Экран |
|---|---|
| `#p-tournaments` | главная (хаб + список турниров); принудительно переключает на BLAST |
| `#p-overview` | обзор турнира |
| `#p-team`, `#p-market` | состав и рынок (`market` скроллит к рынку) |
| `#p-matches` | матчи и статистика |
| `#p-picks` | прогнозы |
| `#p-global` | рейтинг турнира |
| `#p-league` | убран 03.10.2026 (мини-лиги удалены) → главная |
| `#p-alltime` | рейтинг сезона (принудительно BLAST) |
| `#p-howto`, `#p-rules` | как играть и правила |

| `#p-lobby` | редирект на обзор (режим убран) |

Меню: `NAV_GEN` (вне турнира), `NAV_TOUR` (внутри). Нижняя панель — 5 пунктов.

## Состояние (localStorage)
- `df-fantasy-v7-<tourId>` — состояние турнира `S`: `seed, played (сыграно стадий 0–4), lineup {carry,mid,off,soft,hard → playerId}, captain, cash,
  tcArmed, tcUsed, snaps[] (снимок состава на каждую сыгранную стадию + penalty, transfers), pk {questionId → ответ}, ws (состав на начало окна), lobby (мёртвое)`.
- `df-profile` — ник, любимая команда, цвет аватара, уведомления. `df-tour` — текущий турнир. `slam9-howto` — туториал просмотрен.
- sessionStorage `df-splash` — заставка показана в этой сессии.

## Модули (комментарии `// ----------` в коде)
- **Модель матчей**: `STR` сила команды из рейтингов игроков, `playMap` генерирует статистику карты, `runStage(k, seed, ctx)` играет стадию
  (лог серий с картами и статистикой, `pts` очки игроков, `aliveAfter`). `CTX` — сетка между стадиями. `replay()` пересобирает `RES` из seed.
- **Турниры**: `TOURS` из `data/tournaments.json` — The International 2026, BLAST Slam IX (основной), EWC, PGL Wallachia S9, DreamLeague;
  составы пока у всех как у Slam IX. Оформления — по официальным материалам организаторов (docs/10). `switchTour`, `enterTour` (+ заставка турнира).
- **Состав**: `pick`, `drop`, `reason` (почему нельзя купить), `transfers()` — разница с `windowBase()`, `penalty()`.
  **Отмена**: стек `UNDO` (в памяти), `snapLu` перед каждым действием, `undo()`, Ctrl+Z, `revertWindow()` к `S.ws`,
  плашка `renderUndo()` с предупреждением «не хватает на позицию X». После стадии стек очищается.
- **Рейтинг турнира**: 6000 ботов (`buildWorld`) со своими составами и заменами; `myRank()`.
- **Матч-центр**: `renderPoints` — вкладки стадий, серии с таблицами по картам, `mcUpcoming(k)` пары следующей стадии, `STREAMS` ссылки на трансляции.
- **Прогнозы**: `pkQuestions(k)`, `pkResolve`, `pkScore`, `pkStats`, `PK_MED`, `PK_MAX=42`, `renderPicks`.
  Отображение сеткой (03.10.2026): `bkGroups` — каждая группа как мини-сетка GSL (стартовые матчи с выбором → матч победителей/
  проигравших с «твоим прогнозом» пунктиром → решающий → «выйдут из группы»); `bkPlayoff` — одна сетка double elimination на стадии 1–3
  (вкладка подсвечивает серии стадии, открытые — кликабельные); `bkNode` — узел серии. Вопросы и баллы прежние.
- **Рейтинг сезона**: `LEAGUES`, `LG_SHARE`, `SEASON` (раунд 3 из 9, Легенда, группа 8), `seasonGroup()` — 29 ботов из перцентильной полосы + ты, `sgShort()`.
- **Кабинет**: `PF_T` — пример сезона (Wallachia — калибровка, Slam VIII — повышение, Slam IX — живой BLAST), `pfBuild`, достижения `pfAch`, лента, страница турнира.
- **Хаб главной**: `renderHomeHub`, `hmLive` (реальное состояние BLAST), `hmGroup`.
- **Заставки**: `splash()` — стартовая «Сетка» (`DFIntro`, prototype/intro/); `playIntro(skin, done)` — фирменные заставки турниров;
  `tiStage/blStage/ewStage/walStage/dlStage` — экраны перехода после сыгранной стадии.
- **Тестовая панель** «ТЕСТ» (`renderDemo`): «Сыграть: <стадия>» и «Новый турнир». Временная, пока стадии не идут по расписанию.

## Что в прототипе ненастоящее
- Матчи, статистика, очки — симуляция (`runStage`). Рейтинги и цены игроков — оценка «сила команды + надбавка звёздам», не из статистики.
- Коэффициенты ролей `COEF` считаются при загрузке на 2500 симулированных картах.
- Соперники: 6000 ботов в рейтинге турнира, 29 ботов в группе лиги, прошлые раунды сезона в кабинете — пример.
- Составы — заявки Slam VIII. Участники Slam IX не объявлены.

## Оформление
Базовая тема — светлая, токены на `:root`: `--bg #F3F4F1, --surface #FFF, --ink #0B0B0C, --muted #585C56, --line #D3D5CF, --accent #E3361F, --win #1F7A3A, --loss #B3261E`;
шрифты `--display "Saira Expanded"`, `--body "Saira"`, `--mono "IBM Plex Mono"`; без скруглений и теней.
Страницы турнира — в своём оформлении (`[data-skin]` / `data-t`: ti, blast, ewc, wallachia, dreamleague) — по официальным материалам
организаторов (киты BLAST/EWC/ESL, официальные сайты PGL/Valve), с пометкой «Концепт для … · неофициально». Подробно — docs/10.
Логотип сайта — Saira wdth 125 + знак «сетка → красная точка» (в стиле заставки).
