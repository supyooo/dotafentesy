# 01. Продукт

## Позиционирование
Фэнтези по Dota 2, где ты проходишь свой турнир параллельно с реальным: те же стадии, те же игровые дни.
Один аккаунт и один сезон на все тир-1 турниры (BLAST, PGL, ESL, EWC, TI) — фэнтези организатора так не умеет по определению.
На этом же строится B2B: тот же движок под брендом медиа или организатора.

Конкуренты (анализ конца сентября 2026, перепроверить перед питчем): BLAST.tv Dota Fantasy (только турниры BLAST),
Sports.ru «Фэнтези Кибера» (турниры по выбору редакции), Компендиум TI (только TI, платно).

## Режимы и слои
| Что | Суть | Влияет на лигу сезона |
|---|---|---|
| Классика | состав из 5 в бюджет, окна трансферов между стадиями, общая таблица турнира | да — место в группе лиги |
| Прогнозы | исходы серий, выход из групп, чемпион; медаль за долю баллов | нет |
| Мини-лиги | приватная таблица Классики по коду | нет |
| Сезон и лиги | 8 лиг, группы по 30, повышение/вылет после турнира | — |

Убрано: Лобби-драфт (2 октября 2026, решение Georgy — «оставим только классику»). Если вернётся — отдельным решением.

## Экраны (как в прототипе)
Вне турнира:
- **Главная (хаб)** — приветствие; карточка идущего турнира (BLAST Slam IX) с состоянием состава и быстрыми кнопками
  «Перейти в турнир / Мой состав / Рынок / Матчи и трансляции / Прогнозы»; моя группа в лиге (окно вокруг меня + границы зон);
  мини-лиги; полоса сезона; ниже — все турниры списком: идёт / скоро / прошли. Есть режим «экран новичка».
- **Рейтинг сезона** — только своя группа из 30: зоны повышения и вылета, колонки «Раунд» и «Сезон», лестница лиг с числом игроков. Общего топа нет намеренно.
- **Личный кабинет** — карточка менеджера и лиги, путь по лигам (график по раундам), трофеи, медали прогнозов, мини-лиги;
  вкладки «Турниры» (история, страница итогов турнира в оформлении турнира), «Достижения», «Активность».
- **Как играть и правила**.

Внутри турнира (бургер-меню + нижняя панель на телефоне: Обзор, Состав, Прогнозы, Матчи, Рейтинг):
- **Обзор** — стадии турнира, «что сделать сейчас», карточки состава, матчей, рейтинга, прогнозов, мини-лиги.
- **Состав и рынок** — одна страница: пятёрка, банк/трансферы/очки, отмена действий, рынок с фильтрами.
- **Матчи и статистика** — трансляции, вкладки стадий, серии со статистикой игроков по картам, «мой состав по стадиям».
- **Прогнозы** — шкала баллов и медалей, вопросы открытой стадии, итоги прошлых.
- **Рейтинг турнира** и **Мини-лига**.

Вход в турнир сопровождается заставкой в оформлении турнира.

## Словарь
| Термин | Значение |
|---|---|
| Карта | одна игра серии; единица начисления очков |
| Стадия | часть турнира, в которой состав Классики заморожен (у BLAST Slam IX их 4) |
| Дедлайн | начало первой карты стадии; после него состав и прогнозы стадии заморожены |
| Окно | время между концом стадии и дедлайном следующей; только в окно меняется состав |
| Трансфер | замена игрока в Классике игроком той же позиции |
| Банк | непотраченная часть бюджета |
| Раунд лиги | один тир-1 турнир календаря сезона |
| Группа | 30 менеджеров одной лиги в одном раунде |
| Медаль прогнозов | бронза / серебро / золото / платина за турнир |
